Smart Plant Health Monitoring System

About

An IoT project using ESP32 to monitor plant health conditions.

Hardware Components

- ESP32
- Soil Moisture Sensor
- DHT11 Temperature Sensor
- LDR Light Sensor
- Breadboard and Jumper Wires

Features

- Measures soil moisture
- Reads temperature
- Measures light intensity
- Displays sensor readings through the Serial Monitor

Firmware

Arduino code is available in the "firmware" folder.

Setup

1. Install Arduino IDE.
2. Install the ESP32 board package.
3. Install the required sensor libraries.
4. Open "plant_monitoring.ino".
5. Select your ESP32 board and port.
6. Upload the code and open Serial Monitor.

Backend Integration

The backend team will integrate sensor readings with the backend API.
